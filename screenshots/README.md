### How to Take Professional Screenshots:

- **Windows:** Win + Shift + S → Drag → Save as PNG
- **Mac:** Cmd + Shift + 4 → Drag
- **Phone:** Power + Volume Down → Crop
- **Blur keys:** Open in Canva → Elements → Blur → Cover key → Download
- **Fake data only:** Use Test Person, test@email.com, Test Company — never real client data
